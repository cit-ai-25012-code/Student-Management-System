# Student Management System

## Description
A C++ program for managing student records.

## Objectives
- Add students.
- Search students.
- Delete students.
- Display student information.

## OOP Concepts
1. Classes and Objects
2. Encapsulation
3. Constructors and Destructors
4. Inheritance
5. Polymorphism
6. Function Overloading
7. Access Modifiers

## Features
- Add Regular Student
- Add Graduate Student
- Search by ID or Name
- Delete Student
- Display All Students

## Language
C++

## Compile
g++ -std=c++11 main.cpp -o student

## Run
./student
